# Classroom Timetable Generator (PS 92)

## About the Project
This is a Python project that generates a weekly classroom timetable based on the number of days, periods per day, and subjects.

It automatically distributes subjects while following the given scheduling rules.

## Features
- Takes subjects and their weekly periods as input.
- Checks whether the total periods match available slots.
- Allows a maximum of 2 periods per subject per day.
- Gives priority to subjects with more periods remaining.
- Displays the final timetable day by day.
- Handles invalid inputs.

## Concepts Used
Python, Lists, Dictionaries, Loops, Conditional Statements and Input Validation.

## How to Run
1. Open the Python file inside the `Codes` folder.
2. Run it using Python 3.
3. Enter the required details.
4. View the generated timetable.

## Sample Input

Days: 3  
Periods per day: 3

Subjects:
- Maths: 3
- Physics: 2
- Programming: 3
- English: 1

## Sample Output

```text
Mon: Maths, Programming, Maths
Tue: Physics, Programming, Maths
Wed: Physics, Programming, English
```
